# TMLR submission checklist

The anonymous manuscript is `paper/tmlr/main.pdf`. The directory includes the
unmodified official TMLR style files and a self-contained LaTeX source package.

Before submission:

1. Confirm every author's OpenReview profile is active and complete.
2. Upload `paper/tmlr/main.pdf` as the manuscript.
3. Upload `release-assets/tmlr-anonymous-supplement.zip` as supplementary material.
4. Keep the author list, public repository, release DOI, and data DOI out of all
   public submission fields and reviewer-visible comments during double-blind review.
5. Enter the title and abstract exactly as they appear in the manuscript.
6. Declare that the work uses no human participants or private data. Disclose any
   funding and competing interests accurately rather than leaving them implicit.
7. Preview both uploads in OpenReview before the final submit action.

The GitHub-generated Zenodo source archive does not contain the ignored `runs/`
directory. Deposit `release-assets/adversarial-transfer-experiment-records-v1.0.1.zip`
as a separate Zenodo dataset or software-supplement record and upload
`release-assets/ZENODO_SHA256.txt` with it. Relate that record to the project concept
DOI `10.5281/zenodo.22737839` using "Is supplement to." Once Zenodo assigns the
data DOI, add it to the public paper and README in the next public version. Do not
add that DOI to the anonymous TMLR submission while it is under review.
